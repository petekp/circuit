# Reference Map

This folder holds maintenance references that are current but not part of the
operator path.

| Reference | Use it when |
| --- | --- |
| [docs/reference/script-inventory.md](script-inventory.md) | You are adding, moving, or renaming scripts and need the script owner groups. |
| [docs/reference/history-pull.md](history-pull.md) | You are using or changing the gated `circuit history pull` surface, its pull-log, or the relay affordance line. |

Generated output ownership stays in [docs/generated-surfaces.md](../generated-surfaces.md)
because that file is regenerated by the flow emitter.
