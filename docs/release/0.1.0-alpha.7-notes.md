# Circuit 0.1.0-alpha.7 Notes

Date: 2026-06-09

Circuit 0.1.0-alpha.7 is a plugin-only alpha for Claude Code and Codex. The
root `circuit` package remains private in this checkout; npm package publishing
is not part of this alpha.

## Shipping

- Public flow packages: Build, Explore, Fix, Goal, Prototype, Pursue, and
  Review.
- Claude Code: a consolidated plugin command surface. `/circuit:run` is the
  default Circuit command for natural-language coding tasks and routes to the
  right flow with recorded evidence. `/circuit:pursue` is new in this alpha
  and coordinates several related goals as one tracked run. `/circuit:handoff`
  saves, resumes, or clears a deliberate handoff. Direct per-flow commands
  from 0.1.0-alpha.6 (`/circuit:explore`, `/circuit:review`, `/circuit:fix`,
  `/circuit:build`, `/circuit:prototype`, `/circuit:goal`, `/circuit:create`)
  are retired; those flows are routed through Run.
- Codex: bundled Circuit plugin skills and flow files with the same three
  command surfaces (`run`, `pursue`, `handoff`). Codex host behavior uses the
  current model-mediated plugin surface.
- Continuity: ambient capture records recent repo and session state
  automatically. Zero-setup on Claude Code; Codex requires the bundled hooks
  install. Restore surfaces staleness facts against current git state instead
  of assuming the capture is fresh.
- Cross-run memory in bounded, hint-only form: `circuit history`, run-start
  recall, pull logs, memory-effect reports, and local project facts.
- CLI: `./bin/circuit run --goal "<task>"` and explicit flow invocation,
  including `./bin/circuit run pursue --goal "<task>"`.

## New In This Alpha

- Public `/circuit:pursue` slash command on both hosts (REL-PUB-015). Pursue
  was previously routed-only; it now owns `src/flows/pursue/command.md` and
  publishes generated command/skill surfaces for Claude Code and Codex.
- Build runs deep-rigor work as decomposed slices with a per-slice
  implement-and-verify loop.
- Build and Fix plans carry operator intent (non-goals and invariants) into
  review, and reviewers must report alignment against that intent before a
  result is accepted. Code-changing work can additionally prove containment
  to a declared touch area from git evidence.
- Ambient continuity hardening: deterministic survivor selection for the
  restore brief, a pre-compact harvest hook, and a fix that keeps cleared
  handoffs from resurrecting.

## Fix Lite Exception

Bare `fix:` selects the Fix flow at normal depth. Lite requires an explicit
quick, small, tiny, or simple hint, or an explicit `--rigor lite` flag. This
remains tracked as an approved exception in the exceptions ledger.

## Proof And Release Checks

The checked-in release proof set is the proof for this alpha. It covers doing
work, deciding, continuity, customization, failure, first run, and plan
execution through [docs/release/proofs/index.yaml](proofs/index.yaml). The
golden proof runs were re-captured for this release after the `/circuit:pursue`
surface landed.

Use these release checks for this alpha:

```bash
npm run check-flow-drift
npm run check-release-ready
npm run publish:plugins:check
```

Run `npm run capture-proofs:golden-runs` only when a release diff changes
runtime control flow, flow behavior, command semantics, progress, summaries,
reports, checkpoints, or proof scenarios.

## Non-Shipping In This Alpha

- Native Codex App Server and Claude Agent SDK adapters are not part of this
  alpha scope or the current roadmap.
- A separate Codex worker alias. Codex write-capable worker support uses the
  public `codex` connector.
- Automatic keep-up-for-you update channel.
- External same-task comparison demo. Current proof is the checked-in release
  proof set, not an external comparison study.

## Host Support Wording

Describe Claude Code and Codex support as plugin command/skill surfaces with
model-mediated host affordances. Do not describe native Codex App Server or
Claude Agent SDK adapters as planned support, and do not claim a polished
generic-shell human progress surface for this alpha.
