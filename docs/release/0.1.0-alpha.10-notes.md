# Circuit 0.1.0-alpha.10 Notes

Date: 2026-07-05

Circuit 0.1.0-alpha.10 is a plugin-only alpha for Claude Code and Codex,
published from the same consolidated command surfaces as 0.1.0-alpha.9.
The theme of this alpha is first-run honesty: what a brand-new user hits in
their first ten minutes, and what a script can trust about how a run ended.

## Breaking: exit codes tell the truth about unfinished work

The `circuit` CLI exit code now mirrors the closed outcome exhaustively:

- `0`: the run closed complete, or paused at a checkpoint waiting for your
  decision.
- `1`: the run closed short of complete. This now covers aborted, stopped,
  escalated, and handoff closes. Previously an aborted close exited `0`, and
  stopped, escalated, and handoff closes did too, so `circuit run ... && next`
  could chain onto unfinished work.
- `2`: usage errors, unchanged.

Scripts that need to distinguish a deliberate stop from a failure should read
the `outcome` field in the JSON output; the exit code answers only "did the
work complete". The Claude Code launcher renders deliberate closes with the
run's own status text instead of a generic failure line.

## New in this alpha

- `circuit doctor` probes the connector CLIs themselves and names the fix
  when a spawn fails, catching broken installs before a paid run does.
- Running from a directory with no flows now names the searched path and
  offers `--flow-root <circuit checkout>/generated/flows` instead of
  claiming the flow does not exist.
- Resume forgives operator-shaped input (a pasted label, a stray leading
  slash) and answers misses with real guidance instead of a schema error.
- Bare `circuit` is a front door: an interactive shell on a TTY, a static
  survey page when piped. `circuit config` reads and writes configuration.
- `circuit preview <flow>` shows the connector, model, and effort each relay
  would use, marks each value as default or pinned, and bare
  `circuit preview` surveys the public flows.
- Every waiting checkpoint renders a decision-first HTML page on the shared
  design system.
- Host entrypoints guard against Node older than the documented 22.18 floor
  with a plain upgrade message on both hosts.
- A fresh `npm install` reports zero vulnerabilities; the dependency set
  dropped the deprecated transitive glob.

## Release process

This release is the first cut through the standing runbook
([docs/release/runbook.md](runbook.md)). The first-run container lab
(`experiments/first-run-lab/`) ran as a required gate before the version
bump and again after publishing, replaying the documented install funnels
in clean containers with no credentials and no model spend.

## Checks

The standard release gates apply: `npm run verify`,
`npm run check-release-ready`, and the publish gate suite in
`npm run publish:plugins:release`. The publish report for this release is
written to `.circuit/release/plugin-publish-report.json` at publish time.
